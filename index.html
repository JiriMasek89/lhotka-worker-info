Lhotka Mac Worker

Personal desktop automation for generating and checking project drawings with FreeCAD on the owner’s Mac.

What it does

The worker receives project jobs through Google Drive, downloads the required inputs, generates drawing files locally, and uploads results and processing status. A separate coordinator reviews the results before accepting them.

Google Drive access

The app requests read-only Drive access to retrieve existing project inputs and control information, and per-file access to create and manage files associated with the app. Although read permission is broad, the workflow is configured for the owner’s project resources.

This website contains only information about the application. It does not provide access to project documents, drawings, credentials or the worker.
